REQUIREMENTS
------------
* Modern browser: Chrome 100+, Safari 15+, Edge 100+, Firefox 100+
* Internet connection is NOT required for content — everything is local.
  The page only pings CDN for Leaflet map and Tabler icons; if offline,
  those elements degrade gracefully.

TROUBLESHOOTING
---------------
* If videos don't play: browsers usually require the tab to be visible.
  Click somewhere on the page once and they'll autoplay.
* If nothing appears: make sure JBY-V3.3-assets/ folder is in the SAME
  directory as JBY-Home.html.
