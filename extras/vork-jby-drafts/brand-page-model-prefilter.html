Why this layout works

It gives model choice without turning the page into a full catalog.

Filters can feel too heavy on a brand page, but a large lineup still needs structure. This approach uses the model cards themselves as the only filter. The interaction is obvious: pick a model, and the listings below become relevant.

The user does not need to understand all inventory parameters. They only need to answer one easy question first: which model direction interests me?
